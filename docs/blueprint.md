# **App Name**: Meeting Maestro

## Core Features:

- Dynamic Meeting Card Form: Allows users to input meeting details including title, date, start time, end time, and location for each meeting.
- Add Meeting Button: Appends a new, empty meeting card to the list, enabling users to add unlimited meetings.
- Remove Meeting Button: Enables users to delete individual meeting cards, offering flexibility in schedule creation.
- ICS File Generation: Generates a single .ics file containing all entered meetings, formatted according to Vcalendar standards.
- Calendar Download: Triggers the download of the generated .ics file, allowing users to import the schedule into their preferred calendar application.

## Style Guidelines:

- Primary color: Deep indigo (#3F51B5) to evoke trust and professionalism.
- Background color: Light gray (#ECEFF1) for a clean and modern aesthetic, creating comfortable contrast.
- Accent color: Teal (#009688) for interactive elements and highlights, providing a subtle and harmonious pop.
- Body and headline font: 'Inter', a sans-serif font, known for its modern, machined, objective, neutral look, suitable for both headlines and body text.
- Responsive design that adapts seamlessly to different screen sizes.
- Use clear, simple icons to represent actions such as adding or removing meetings.
- Subtle transitions when adding or removing meeting cards to enhance the user experience.
